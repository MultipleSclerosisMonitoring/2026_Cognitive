Cognitive Calibration
=====================

Documentation for the typed Python pipeline that validates and calibrates
mobile SDMT and TMT assessments against paper-based clinical outcomes.

The documentation distinguishes the implemented software from the recommended
research protocol. The generated API reference is based on the Python source
and its Google-style docstrings.
